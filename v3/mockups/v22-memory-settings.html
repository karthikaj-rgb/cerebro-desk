Why not a modal or a drawer

  • A modal blocks the list you're checking against.
  • A drawer hides the state: you can't see that Notes is off without opening it.
  • The panel shows the state and changes in one tap, so it's both the summary and the control.

What moved where

  • Learns from → switches with a count of facts each source gave.
  • Sharing → one bar: team vs only you.
  • Rules → the 4 most important, with “AI team ›” for the rest.
  • History → last 3 with Undo; “All history ›” for the full log.
