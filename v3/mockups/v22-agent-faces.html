Agent faces · options

Each agent gets a living face in its own colour, not a letter tile. They breathe when idle, work when working, call for you when they need you, and move with the voice when talking. Hover to get their attention, click to poke them. Same face from the 22px sidebar to the profile.

My picks: A · Stitch carries V2’s pixel language into each agent and reads well tiny. B · Goo is the most fun and personal. Could combine: Stitch tile for the sidebar, Goo creature on the profile and when an agent talks.
