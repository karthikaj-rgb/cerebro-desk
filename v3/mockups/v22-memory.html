Memory as HighLevel's memory

Memory stops being a list of AI notes and becomes one place for everything HighLevel knows about you, your agency, each client and each contact. What already lives in HighLevel is shown live from HighLevel. What the AI learns from calls, emails and edits is added on top, with its source. Every agent and product reads from the same memory.

0

How it works

Three layers, one memory. Facts come in from everywhere in HighLevel, are kept per agency → client → contact, and every AI product uses them.

Comes in from
  • Contacts, custom fields, notes
  • Conversations: SMS, email, DMs
  • Call recordings and Voice AI
  • Calendars, pipelines, invoices
  • Brand boards, sites, forms
  • What you say and edit in Cerebro
→learned, with a source
Kept as one memory
  • You: how you like to work
  • Agency: brand, pricing, playbooks, team
  • Each client: goals, brand, contacts, what works
  • Each contact: preferences, history
→permission-aware
Used by
  • Cerebro and the AI team
  • Conversation AI and Voice AI
  • Content AI, Reviews AI
  • Workflows and reports
  • Writes back to HighLevel fields

What changes from today's Memory sheet

Less to manage, more that's useful.

Remove or move

  • Rules tab → AI team. They're permissions for agents, not things to remember.
  • On/off switch on every row → gone. Keep, edit or forget is enough; “paused” facts confuse.
  • All / Team / Only you filter → one visibility chip per fact, edited from ⋯.
  • “Learns from” chips → Sources, in settings.
  • Changes tab → History, per fact and in settings.

Keep

  • To review first: nothing new is shared until you keep it.
  • Source on every fact (call, email, edit, note).
  • You vs team visibility.
  • Search, now as a question (“What does Harbor care about?”).
  • The memory chip in chats (“Used memory · …” and “Why?”).

Add

  • From HighLevel · live: contacts, plans, brand, calendars, shown not copied.
  • Agency → client → contact levels, with 1,284 clients searchable.
  • Used by: which agents and products rely on a fact.
  • Save to HighLevel: turn a learned fact into a real field.
  • Sources and who-sees-what settings for the agency.
